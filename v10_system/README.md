# 香港六合彩 V10：可重現研究與可靠發布

此重建版保留導入的官方資料及 V9 封存帳本原始位元組，不追認舊庫錯誤来源，也不把歷史回測說成實戰勝率。

## 操作

POSIX 環境（建議 Linux；Windows 使用 WSL）、Python 3.10+ / numpy（見 requirements.txt）。在本目錄執行：

- `python -m v10 build`：用已核驗快照重算。明示離線快照，不聲稱剛完成官方更新。
- `python -m v10 update`：向 HKJC 完整核對最近約六個月及即將開獎資訊；任何來源、缺期、衝突、格式錯誤均中止發布。
- `python -m v10 verify`：驗證現行發布全部檔案雜湊、資料、封存帳本及 HTML 身分。
- `python -m unittest discover -s tests -v`：原有回歸測試與 V10 故障測試。
- `python -m http.server 8000 --directory current`：本地瀏覽 latest_battle_report.html。

`current` 是原子切換的符號連結，指向一組完整不可變的 `releases/<release_id>/`。資料、來源憑據、新帳本、分析、健康、版本及報表共同切換，失敗保留最後一組已驗證結果。同步更新使用作業系統鎖。禁止用逐檔上傳覆蓋線上發布目錄；託管端須使用原子部署整組輸出。瀏覽器刷新只重新讀取報表，不假裝觸發雲端重算。

## 科學邊界

- 固定一個號碼命中六個正碼之一，公平基準 6/49；命中特別號基準 1/49。模型只研究正碼排序，不提供特別號優勢。
- 前 400 期選模型、後 120 期評估，每期只用之前資料。五模型多重比較修正。這是滾動歷史探索，不是預先註冊的獨立前瞻驗證。
- bayes_60 是最近 60 期頻數排序，平手取較小號碼。平滑不增加額外排序資訊，排序分數不是中獎機率。
- V10 正式單號保持空白。尚無預先註冊的前瞻證據，因此即使某次歷史 p 值變小，也不自動批准正式單號。
- 研究號碼及封存號碼分開；同一期重算不覆寫既有封存。連續重複不視為信心增加。
- 沒有官方確認的下期期數/日期就顯示待確認。沒有經核實的精確開獎截止時間，保守排除香港開獎當天才建立的封存成績。
- V9 歷史帳本原封保留，與 V10 成績分開；雜湊鏈能揭示局部修改，但不是獨立第三方時間戳證明。

## 資料與稽核

保留來源 CSV 3,324 期，2003-01-02 至 2026-10-10，26/108，SHA256 6969b8a75917b2d284a766abe1b4700201cb3e39aaaffdb81ebd07eae2b18b48。逐列核對真正日期、香港未來日期、年度與來源 ID、一年從第 1 期開始的連續期號、七個不同 1..49 球、排序、manifest 範圍/筆數/雜湊。逐年期數連續不能自行證明年底無遺漏，原始全史抓取聲明也不是本次獨立重新核對；報表不冒稱全史新審計。

來源憑據超過 24 小時即過期；離線生成不能刷新來源時間。執行時間、資料 SHA、程式 SHA、發布 SHA 都能追溯。舊資料與 V9 模組保留供回歸追溯，V10 入口不使用舊可變發布流程。
