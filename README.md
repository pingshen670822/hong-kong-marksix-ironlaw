# 香港六合彩新世代鐵律預測系統

以最新版台灣大樂透系統的乾淨室統計架構重製，完整改用香港六合彩規格：1–49選6個正選號碼、另開1個特別號、七級獎制與每注HK$10。

## 系統特色

- 歷史資料自1993-01-05起，每次更新後自動重算期數與最新日期
- 正選號碼與特別號分開建模
- 520期嚴格時間序列走步回測，禁止偷看未來
- Bayesian、EWMA、間隔危險率、條件共現及狀態斜率集成
- 預測先封存，開獎後只結算，不回改舊牌
- 手機版離線戰報、八組平衡單式、短包、低機率區與月結
- 內建香港六合彩七級獎項判定
- 比照539鐵律的雙軌治理：開獎資料更新與預測信心守門分離
- 雙來源交叉核對、逐期結算、完整性稽核、健康檢測與四次自主修復
- 模型未達門檻時只降級為觀察排序，不得阻斷最新資料同步或冒充高信心

## 使用方式

在本資料夾執行：

```powershell
python watchdog.py
python daily_integrity_audit.py
python verify.py
python health_check.py
```

或右鍵以 PowerShell 執行 `一鍵更新並檢測.ps1`。完成後開啟 `reports/index.html`。

## 規則基準

- 單式：1至49選6個號碼，每注HK$10。
- 一獎至七獎條件依香港賽馬會2026年3月30日版獎券規例。
- 四至七獎固定為HK$9,600、HK$640、HK$320、HK$40。
- 開彩日期可因金多寶及節日調整，最終以香港賽馬會公告為準。

## 重要聲明

每期開獎是獨立隨機事件。排名、短包與組合只供統計研究，不保證中獎；請量力而為，未滿18歲不得投注。
