# 香港六合彩新世代鐵律預測系統

以最新版台灣大樂透系統的乾淨室統計架構重製，完整改用香港六合彩規格：1–49選6個正選號碼、另開1個特別號、七級獎制與每注HK$10。

## 系統特色

- 歷史資料自1993-01-05起，每次更新後自動重算期數與最新日期
- 正選號碼與特別號分開建模
- 新核心 v8：520期依時間順序重播實際發佈的獨隻與前9碼；前400期選策略，末120期固定策略評估
- Bayesian、EWMA、間隔危險率、前一期單錨／雙錨對下一期的轉移及狀態斜率集成
- 同時比較機率集成、49碼候選競賽、排除上期開出號及連開三期防守；只由前400期選擇，不用末120期回頭挑規則
- 回顧式走步與開獎前封存實戰分開公布；模型估計值不能當作保證命中率
- 預測先封存，開獎後只結算，不回改舊牌
- 手機版離線戰報、八組平衡單式、短包、低機率區與月結
- 內建香港六合彩七級獎項判定
- 比照539鐵律的雙軌治理：開獎資料更新與預測信心守門分離
- 雙來源交叉核對、逐期結算、完整性稽核、健康檢測與四次自主修復
- 模型未達門檻時只降級為觀察排序，不得阻斷最新資料同步或冒充高信心
- 戰報採539同規格六大分類介面：本期預測、回測驗證、開獎檢討、歷史封存、模型說明、系統健康
- 手機首頁提供「手動更新最新」與「當機立即修復」；前者強制核對最新期別並以台北時間永久保留最近完成時間，後者清除失效快取、重連雲端，來源仍異常時導向第二層雲端救援
- 背景版本檢查與完整資料抓取分離；單一快取檔案失敗不會再中止整個離線服務安裝
- 版本切換同時比對雲端產生時間，舊快取雜湊不得觸發回載，避免代理快取不同步造成重整循環

## 使用方式

在本資料夾執行：

```powershell
python watchdog.py
python daily_integrity_audit.py
python verify.py
python health_check.py
```

或右鍵以 PowerShell 執行 `一鍵更新並檢測.ps1`。完成後開啟 `reports/index.html`。

## 規則基準

- 單式：1至49選6個號碼，每注HK$10。
- 一獎至七獎條件依香港賽馬會2026年3月30日版獎券規例。
- 四至七獎固定為HK$9,600、HK$640、HK$320、HK$40。
- 開彩日期可因金多寶及節日調整，最終以香港賽馬會公告為準。

## 重要聲明

每期開獎是獨立隨機事件。排名、短包與組合只供統計研究，不保證中獎；請量力而為，未滿18歲不得投注。
